Política de Privacidade – PostBot Pro

Última atualização: 25 de setembro de 2026.

Esta Política de Privacidade explica como o PostBot Pro trata informações necessárias para fornecer suas funcionalidades de automação e publicação em redes sociais.

1. Informações utilizadas

O serviço poderá utilizar informações fornecidas pelo usuário e dados necessários para conectar contas de redes sociais autorizadas pelo próprio usuário.

2. Autorização das contas

O acesso às plataformas integradas deve ocorrer somente após autorização do usuário através dos mecanismos oficiais disponibilizados por cada plataforma.

3. Conteúdo

Vídeos, textos e outros conteúdos fornecidos pelo usuário serão utilizados somente conforme necessário para executar as funcionalidades solicitadas pelo usuário.

4. Compartilhamento

Informações poderão ser transmitidas às plataformas escolhidas pelo usuário quando isso for necessário para realizar uma publicação ou outra ação solicitada.

5. Segurança

São adotadas medidas razoáveis para proteger as informações utilizadas pelo serviço contra acesso não autorizado.

6. Exclusão de dados

O usuário poderá solicitar a exclusão de informações associadas ao serviço através dos meios de contato disponibilizados pelo PostBot Pro.

7. Alterações desta política

Esta Política de Privacidade poderá ser atualizada para refletir mudanças no serviço ou nas plataformas integradas.

8. Contato

Dúvidas ou solicitações relacionadas à privacidade poderão ser encaminhadas através dos meios de contato disponibilizados pelo PostBot Pro.
